我一直觉得，学过的东西如果没有写下来，过一阵子就只剩下"我好像学过"的印象。

所以我搭了这个博客。它不复杂：文章写在 Markdown 文件里，GitHub Actions 把它们编译成静态 HTML，再发布到 GitHub Pages。

## 我想记录什么？

- 学到的新概念，尤其是当时卡住我的那些
- 做项目时踩过的坑和最后的解决办法
- 读过的文章和书里值得留下的一句话
- 下一步想尝试的事情

## 为什么不用现成的博客平台？

现成的平台注册就能写，但我想顺便把"网页是怎么做出来的"这件事弄明白。自己搭一遍，至少知道了下面这几件事：

1. 一个网站本质上就是一堆 HTML 文件
2. CSS 负责让这些文件好看、好读
3. 静态站点不需要服务器，谁都能托管

## 接下来

我会尽量保持一个简单的节奏：学到什么就写什么，不追求篇幅。

写博客最难的部分大概不是技术，而是坐下来把想法整理成别人也能看懂的文字。这也正是我想练的东西。
