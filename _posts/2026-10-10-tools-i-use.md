工具不需要多，够用就好。下面是我现在真正在用的东西。

## 写文章

**VS Code**，装一个 Markdown 预览插件就够了。左边写、右边看，改完直接保存。

文章就是普通的 `.md` 文件，放在 `_posts/` 目录里，文件名要写成 `YYYY-MM-DD-标题.md` 这种格式。

## 保存和发布

**Git** 负责记录每一次修改，**GitHub** 负责存放这些记录。我记不住复杂的命令，所以常用的只有四个：

```text
git status              看看我改了什么
git diff                看看具体改了哪几行
git add .               把改动放进暂存区
git commit -m "说明"     提交，并留下一段说明
```

写完再 `git push` 一下，博客就会自动重新构建。

## 值得看的资源

- **MDN Web Docs**：HTML 和 CSS 的文档。遇到不认识的属性，我第一反应是去这里查，而不是去搜博客。
- **Can I use**：查一个 CSS 属性在各个浏览器里的支持情况。
- **GitHub Docs 的 Pages 章节**：搞清楚 Actions 和 Pages 是怎么配合的。

## 一条给自己的规则

同时只学一个工具。看到别人推荐的十件套清单，先记下来，等真的需要了再装。

工具是用来解决问题的，攒工具本身不是。
